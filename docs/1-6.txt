2. BACKEND

Backend menggunakan REST API.

Endpoint:

POST
/api/follow-ups

GET
/api/follow-ups/customer/:customerId

GET
/api/follow-ups/:id

PUT
/api/follow-ups/:id

DELETE
/api/follow-ups/:id


2.1 CREATE

POST digunakan untuk membuat Follow-up baru.

Data yang dikirim:

{
  customerId,
  note,
  followUpDate
}

Controller menerima data dari:

req.body

Kemudian controller memanggil:

followUpService.createFollowUp()


2.2 READ

GET berdasarkan customer:

/api/follow-ups/customer/:customerId

Digunakan untuk mengambil semua Follow-up milik satu customer.

Service menggunakan:

WHERE customer_id = $1

Hasil diurutkan berdasarkan:

ORDER BY created_at DESC


2.3 UPDATE

PUT digunakan untuk mengubah Follow-up.

Endpoint:

/api/follow-ups/:id

Data yang dapat diubah:

- note
- followUpDate

SQL menggunakan:

UPDATE follow_ups
SET
  note = $1,
  follow_up_date = $2,
  updated_at = CURRENT_TIMESTAMP
WHERE id = $3


2.4 DELETE

DELETE digunakan untuk menghapus Follow-up.

Endpoint:

/api/follow-ups/:id

SQL:

DELETE FROM follow_ups
WHERE id = $1

DELETE membutuhkan ID Follow-up.

Customer ID tidak dapat digunakan untuk endpoint DELETE.

Jika Follow-up tidak ditemukan, backend mengembalikan:

404
Follow-up not found


3. FRONTEND

Frontend menggunakan React.

File baru:

src/services/followUpApi.js

File ini digunakan untuk menghubungkan React dengan API Follow-up.


3.1 GET FOLLOW-UP

Function:

getFollowUpsByCustomerId(customerId)

Function ini melakukan request:

GET /api/follow-ups/customer/:customerId

Hasil response digunakan untuk mengisi state:

followUps


3.2 CREATE FOLLOW-UP

Function:

createFollowUp()

Mengirim data:

{
  customerId,
  note,
  followUpDate
}

Setelah berhasil, Follow-up baru ditambahkan ke state.


3.3 UPDATE FOLLOW-UP

Function:

updateFollowUp()

Menggunakan method:

PUT

Setelah berhasil, data Follow-up pada state diperbarui.


3.4 DELETE FOLLOW-UP

Function:

deleteFollowUp()

Menggunakan method:

DELETE

Setelah berhasil, Follow-up dihapus dari state menggunakan:

filter()

5. STATE REACT

Beberapa state baru:

followUps

Digunakan untuk menyimpan daftar Follow-up.

note

Menyimpan isi catatan Follow-up.

Menyimpan tanggal Follow-up.

Menyimpan ID Follow-up yang sedang diedit.

8. KONSEP PENTING

useState()

Digunakan untuk menyimpan data yang dapat berubah.

Contoh:

const [note, setNote] = useState("");


useEffect()

Digunakan untuk menjalankan proses ketika halaman dimuat atau ID customer berubah.

Contoh:

useEffect(() => {
  fetchData();
}, [id]);


map()

Digunakan untuk menampilkan banyak Follow-up.

Contoh:

followUps.map((followUp) => (
  ...
))


filter()

Digunakan untuk menghapus item tertentu dari state.

Contoh:

setFollowUps((currentFollowUps) =>
  currentFollowUps.filter(
    (followUp) => followUp.id !== followUpId
  )
);


async/await

Digunakan untuk menjalankan request API secara asynchronous.

Contoh:

const data = await getCustomerById(id);
